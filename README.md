# AVATAR_Media
Lecteur multimédia graphique intégré à A.V.A.T.A.R (Electron)

This plugin is an add-on for the [A.V.A.T.A.R](https://avatar-home-automation.github.io/docs) framework.

🎯 Usage
Commandes :

- Radio et avec askme
- chaine télé , met la chaine tf1 ect , les chaine sont sur fichier json
- films, videos, series en local sur vos vos repertoires
- musique en local sur vos vos repertoire
- playlist a creer des dossiers exemple : pop, rock, jazz, reggae, groove ect

# Multi-room
The AVATAR_Media plugin is fully multi-room.

# Multi-language
The AVATAR_Media plugin relies solely on the system's available languages.
